# Маяк

Проект «Маяк» запущен 19 июня 2025 года.

Регистрационный код проекта «Маяк»: MAY-826.

Это вымышленный проект для проверки поиска по документам. Команда ведёт журнал изменений, готовит замечания и архивирует утверждённые материалы. Перед использованием сводки необходимо свериться с первоисточником. Пилот предназначен для поиска внутренних сведений. В руководстве отсутствуют финансовые результаты, численность команды, клинические результаты и личные контакты.
